Digital Content Supply Chain Visibility & Analytics Dashboard

📌 About the Project

This project was developed as part of the Infosys Springboard Virtual
Internship. The project focuses on analyzing digital content supply
chain data and presenting meaningful insights through an interactive
Power BI dashboard.

• Power BI
• Microsoft Excel
• Data Visualization
• Data Analysis

• Supply chain analysis

• Trend analysis
