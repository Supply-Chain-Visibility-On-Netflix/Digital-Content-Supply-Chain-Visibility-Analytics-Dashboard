# 🎬 Netflix Data Visualization & Analytics Dashboard

## 📌 Project Overview

The **Netflix Data Visualization & Analytics Dashboard** is a Power BI-based data visualization project developed to analyze and understand Netflix content and its performance.

The main purpose of this project is to transform raw Netflix-related data into meaningful visualizations and interactive dashboards. The dashboard helps users understand content distribution, genres, regions, views, watch hours, and revenue through simple and interactive visuals.

---

## 🎯 Objectives

The main objectives of this project are:

* To analyze Netflix content using data visualization techniques.
* To clean and prepare the dataset for analysis.
* To identify patterns and trends in Netflix content.
* To analyze content based on genre and region.
* To understand views, watch hours, and revenue.
* To create interactive dashboards using Power BI.
* To present important business insights through KPIs and visualizations.

---

## 🛠️ Tools & Technologies

* **Power BI** – Data visualization and dashboard development
* **Power Query** – Data cleaning and transformation
* **DAX** – Creating calculated measures and KPIs
* **Microsoft Excel / CSV** – Dataset storage and preparation
* **GitHub** – Project file storage and team collaboration

---

## 📊 Dataset

The project uses Netflix-related datasets containing information about content and its performance.

The data includes fields such as:

* Movie/Content ID
* Genre
* Region
* Revenue
* Watch Hours
* Views
* Release Date
* QC Status
* Stage
* Content-related information

The datasets were imported into Power BI and prepared for analysis.

---

## 🧹 Data Cleaning & Preparation

Before creating the dashboard, the data was cleaned and transformed using Power Query.

The following steps were performed:

* Removed duplicate records.
* Handled missing/null values.
* Removed unnecessary or invalid records.
* Checked and corrected data types.
* Removed zero or incorrect values where required.
* Standardized the dataset for analysis.
* Created relationships between relevant tables.

This ensured that the data was suitable for accurate analysis and visualization.

---

## 📈 Dashboard Development

An interactive dashboard was developed using **Microsoft Power BI**.

The dashboard provides a visual overview of Netflix content and its performance.

### Key Performance Indicators (KPIs)

The dashboard includes important KPIs such as:

* **Total Revenue**
* **Total Inventory**
* **Total Views**
* **Total Watch Hours**
* **Published Content Percentage**

These KPIs provide a quick overview of the overall performance.

---

## 📊 Visualizations

The dashboard contains different charts and visualizations to analyze the data from multiple perspectives.

### Content Analysis

* Content distribution by genre
* Content distribution by region
* Release date analysis
* Content inventory analysis

### Performance Analysis

* Revenue analysis
* Views analysis

### Quality & Publishing Analysis

## 🔍 Key Insights

The dashboard helps identify important patterns such as:

* Which genres have the highest amount of content.
* Which regions contribute significantly to content performance.
* Which content generates higher views and watch hours.
* How revenue varies across different regions and content categories.
* The distribution of content across different stages.
* The percentage of content successfully published.
* Areas where content quality or publishing processes can be improved.
